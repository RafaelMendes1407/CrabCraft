# Screenshot sources and reproduction

These PNGs are unmodified captures of CrabCraft's native Rust/egui interface,
rendered offscreen by `egui_kittest` and wgpu. They are not browser mockups.
The sample Rust projects are generated by the repository's own tests; no private
project, credentials or third-party source files are shown.

## Reproduce

From the repository root, with a working graphics backend, Rust toolchain,
rust-analyzer and GDB installed:

```sh
cargo test -p rc-app --locked --offline documentation_feature_captures -- --ignored --test-threads=1
```

The ignored test is defined in `crates/rc-app/src/rust_tests.rs`. It creates
temporary Cargo projects and isolated application settings, explicitly trusts
the projects, then exercises real tools. It requires GDB rather than silently
skipping the debugger image when the adapter is unavailable. Generated images
are written to `target/snapshots/`; review them before copying into this folder.

| Published image | Generated image | Source of the displayed state |
| --- | --- | --- |
| `overview.png` | `docs-overview.png` | Real Cargo project, Rust analysis and native editor. |
| `completion.png` | `docs-completion.png` | Method completion returned by installed rust-analyzer. |
| `tests.png` | `docs-tests.png` | Results of a real `cargo test` run, with one passing unit test. |
| `call-hierarchy.png` | `docs-call-hierarchy.png` | Callers returned by installed rust-analyzer. |
| `debug.png` | `docs-debug.png` | Real GDB session stopped at a Rust breakpoint, with locals and a watch. |

No protocol responses, test results or debugger values are fabricated. Captures
show supported examples, not proof of all platforms or every documented capability.
The offscreen harness does not establish native compositor behavior on Wayland
or Windows.
