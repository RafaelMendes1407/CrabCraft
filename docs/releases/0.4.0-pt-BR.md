# Anúncio para Discord — CrabCraft 0.4.0

🦀 **CrabCraft 0.4.0 chegou!** Uma nova etapa da nossa IDE nativa para Rust, feita com Rust e egui.

• Refatorações como Change Signature e Move Items, expansão de macros e melhorias na navegação Rust.
• Abertura, salvamento e restauração de arquivos em segundo plano, com cancelamento e proteção das edições.
• Debug com GDB/LLVM LLDB DAP, múltiplas sessões e pilhas paralelas.
• Workspace Rust via SSH e deploy revisado por SFTP/FTPS explícito.
• Integrações opcionais: HTTP com ambientes, ferramentas web, SQLite/PostgreSQL local, Ollama e agentes ACP.
• Documentação reorganizada e avisos de licença incluídos nos pacotes.

O inventário registra **246 recursos prontos, 7 parciais e 5 fora de escopo**, com evidências e limites por recurso. Continuamos em **preview**: WSL real, Ferrocene, upload público no Playground, execução/debug como administrador e fluxos Docker/Dev Containers ainda têm pendências. CI no Windows não significa validação da interface nesse sistema.

🔒 Abrir um projeto não executa seu código; as ferramentas Rust exigem confiança explícita. Integrações externas dependem de instalação/configuração separadas.
